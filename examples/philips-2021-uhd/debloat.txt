# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philips-2021-uhd/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher. It is not in this list. Installing the
# launcher (launcher/build-and-install.sh) disables it so Home opens com.gathin.tvhome.
# restore.sh re-enables it and sets it back as Home. Live TV app: org.droidtv.playtv.
#
# Kept on purpose: Ambilight (org.droidtv.ambiair, org.droidtv.ambihuecommon), HDMI, the
# tuner, the remote, Play Store, Google Play services, and Chromecast
# (com.google.android.apps.mediashell). Do not add those here.
#
# Launcher for this set: French strings in launcher/app/src/main/res/values-fr/, dock in
# launcher/app/src/main/res/values/config.xml (OQEE / Free, Crunchyroll, ADN, Netflix).
# Prime Video, Apple TV, YouTube, Disney+ and France TV stay installed; they are just not
# pinned to the four dock slots.
#
# Screensaver was pointed at com.gathin.tvhome/.ClockDream. screen_off_timeout was left at
# 604800000 (Philips "never", 7 days), so the clock dream does not appear unless that
# timeout is shortened. That timeout is a whole-TV setting, relevant on an OLED.
